# AI-Powered RAN Trial Analysis with Claude Cowork & Claude Code

Training deck for an AI-assisted workflow that analyses RAN optimisation trials (4G LTE and 5G NR NSA/EN-DC, Nokia RAN).
The workflow produces three deliverables from one KPI export:

- KPI trend charts (Excel)
- Statistical analysis with sigma significance and causal-chain KPI trajectories (Excel)
- Technical memo with a verdict (Word)
